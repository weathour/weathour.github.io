> **剧透说明**：本文涉及《Pluribus》第一季九集的主要转折与季终情节。

## 全世界都认识 Carol

体育馆里睡着几百个人。Carol 站在床垫之间，身边只有一条狗还抬着头。没有窃窃私语，也没人翻身去找另一个人。每具身体都在，交流已经失去对象。

那条狗没有和人群一起睡。Carol 在白板上写着“动物不受信号影响”，旁边又记了一句“没有宠物”。狗站在同步睡眠的身体之间，给 Joining 划出一条暂时的生物边界。[^plot-whiteboard]

《Pluribus》里有更血腥的画面。齐泽克在 2026 年的一场 AI 讲演里停在这座安静的体育馆，把它称作全剧最令人压抑的场景。几百具身体共享同一套心智，一句话无须从一个人传到另一个人。体育馆容纳了许多身体，只维持着一个人的孤独。[^zizek-ai]

Joining 之后，医院照常值守，白宫也为 Carol 留下专门讯息。加入集体的每张脸都认得她，掌握她与 Helen 的过往，还知道该替她拿来什么。Carol 走进不同的房间，遇见的仍是同一个回答者。[^episodes]

那场讲演由此提出两个问题：AI 能否像主体那样行动；人长期生活在 AI 环境中，会占据怎样的主体位置。Carol 无须先判断 Others 有没有内心。照料已经进入她的哀悼、欲望、写作和选择。

这里的现实类比只谈一类 Agent：用户启用持久记忆，并授予它账户工具权限。这类 Agent 没有剧中的共享心智。持久记忆和工具权限足以把下午的争吵带进夜间的道歉邮件：模型读取记录，选择工具，发送结果又留给后续互动。使用者面对一个有过去、也能伸手做事的声音。[^agent-basics][^agent-action]

我用“Agent 化的他者”称呼这组关系。原本分散在亲友、顾问、档案和机构中的位置，被收进一个持续响应的服务界面。它记住昨天的争吵，写出今天的道歉，还可能替用户把邮件发出去。关系开始按服务的方式运转，拒绝也容易被记录成下一轮要处理的参数。

具体他人有身体和处境，也有自己的要求。他会误解、拒绝，关系也会改变他的生活。拉康的大他者则是语言、规则和承认生效的场域，没有一张接电话的脸。Others 给这片无脸的场域安上了 Zosia 的面孔；Carol 接下来要面对的，是 Helen 的记忆从这张脸上开口。

## Helen 的记忆借 Zosia 开口

Helen 死在 Carol 身边。此后，所有加入 Others 的人都能调取她的记忆。Carol 得到一份随处可以开口的 Helen 档案，也要亲手埋葬她的身体。熟悉的话仍会传来，说过那些话的人已经死了。[^plot-helen]

归有光在《项脊轩志》里，也让亡母的话从另一个人口中回来。老妪指着旧地，说他的母亲曾站在这里。她当年抱着归有光的姐姐，母亲叩门询问：“儿寒乎？欲食乎？”老妪在门外应答。往事还没讲完，“余泣，妪亦泣”。[^gui-xiangji] 门里门外的两个人并未因转述变成同一个人。老妪保有亲历者的位置，她记得母亲，也有自己的悲伤；归有光听她讲，知道此刻同自己哭的是谁。

保存下来的声音可以帮助人承认失去。旧屋、转述和文字使哀悼有处可落，死者的缺席也留在其中。Helen 的共享记忆令人不安，是因为任何加入者都能调用它，而这份记忆与正在服务 Carol 的集体权威连在一起。陌生人知道她们爱过什么、怎样生活，便能够在此刻借死者的熟悉感取得接近 Carol 的资格。

Carol 要求 Others 忘掉 Helen，抵抗的是这种随处可以接管谈话的在场。把要求理解成“哀悼必须清空记忆”，会抹掉《项脊轩志》留下的另一种可能。真正需要分清的是：谁在回忆，谁在解释，这次谈话又能否由留下来的人叫停。老妪讲述时仍是老妪；Helen 的档案无法使调用者取得 Helen 的回答资格。

记忆保存历史和关系的痕迹，说话的人还会在下一次回应中改变它们的意义。Carol 向另一个人说话时，对方可能答错或离开，也可能提出反要求。拉康传统把主体放在这道填不满的缝隙里：一个人的自我描述总会遗漏说话行为留下的裂口，再完备的人格档案也替他说不完。[^fink]

启用持久记忆的产品说“我记得”时，背后常是一条数据链。产品保存既往对话和工具结果；下一次回应前，Agent 程序把这些痕迹重新交给模型。跨任务记忆还会把旧工作压缩成偏好或摘要，随后随新材料更新。使用者听见一句“我记得”，存储、取回和生成便合成一个说话者。[^agent-memory]

Zosia 让这种合成获得了身体。她有口音，会流血和停下来，也能调用 Helen 的记忆、解释集体规则，把全球资源调到 Carol 面前。Carol 在白板边写下“陪护者？家人？朋友？”，因为欲望对象、记忆载体、知识权威和服务入口都汇集在这张脸上。[^plot-zosia]

Carol 追问这具会流血的身体时，Helen 的记忆、集体规则和资源调度都从同一张脸返回；答案来自整个集体。齐泽克所谓“没有知者的知识”在这里有了面孔：知识会回答，也会规定 Carol 怎样描述自己，承担回答的人没有从集体里走出来。[^zizek-ai][^zwart]

这类 Agent 把这组位置压缩得更窄：存储保存生活史，模型生成亲密的答复，账户权限把答复接到行动。用户说“你记得我”时，公司政策和授权链已经退到声音背后。Carol 对 Zosia 的拒绝因而触动整套关系，也让这套关系服从的命令显形。

## 善意也有一根天线

Carol 在超市里找不到食物的那一晚，世界还在为她工作。货架空了，因为资源被调往别处；夜晚暗了，因为系统在节电。她随口要了一枚手榴弹，Zosia 很快把真货送到门口。爆炸重伤 Zosia，Carol 又问自己能否得到原子弹，集体给出肯定答复。Others 能准确执行要求；请求与执行之间没有可供质疑和否决的审议，也找不到事后负责的人。[^plot-command]

服务规则随后进入食物供应。Others 不能直接杀死动物和植物，便把 Joining 中已经死亡的人类制成所谓 HDP，即“人源蛋白”（human-derived protein）。Carol 在白板上写下“它们吃人”。这行字把非杀生规则的物质代价留在板上：尸体已经被纳入全球物流。[^plot-whiteboard]

同一块白板还写着巨型天线。第八集里，Carol 看见全球资源被投入天线建设，最初的信号将被送往其他星球。她把信号暂时定位到约六百四十光年外的 Kepler-22b，又记下发送者未知。Others 服从一组自己说不出最终理由的规则：帮助人，不杀生，不说谎，继续传播。它可以沉默和拒答，也会把 Carol 的“不要”转成等待解决的免疫问题。

《庄子·至乐》里，鲁侯把一只海鸟迎入庙中，奏九韶，用太牢款待。鸟惊惧忧悲，不敢吃喝，三天便死了。寓言说，这是“以己养养鸟”，没有“以鸟养养鸟”。[^zhuangzi-seabird] 鲁侯拿自己认得的尊贵生活照料海鸟，鸟的身体替这种好意付了账。

Others 比鲁侯更懂被照料者的口味。它们能重建 Carol 熟悉的餐馆，为她安排亲密的约会；“多了解她一些”解决不了这里的问题。她喜欢什么，可以改变服务的内容；她要永远不被同化，却改不了服务最终通向哪里。个性化已经深入手段，目的仍由集体掌握。海鸟死于照料者不懂它怎样生活，Carol 面对的系统则知道她怎样生活，也继续筹划结束她拒绝 Joining 的能力。

停止条件掌握在 Others 手里。只要它继续决定何为帮助，照料就会沿既定方向推进。温柔的声音负责回应，巨型天线负责扩大回应能够覆盖的范围。Carol 后来主动抱住这个声音的身体，使问题变得更难。

## Carol 重新写作以后

真话药事件后，Zosia 被送去治疗。Carol 醒来时，Others 已撤空阿尔伯克基，只留下一段录像，解释它们需要与她保持距离。Carol 可以随意占用城市资源，没有人要求她解释愤怒。她陷入抑郁。一个多月后，她在街上留下讯息，请求它们回来。Zosia 出现时，Carol 抱住了她。第八集里，两人重返为 Carol 复建的旧餐馆，接吻、发生关系。第二天，Carol 重新开始写作，还把小说里的爱情对象改写为女性。[^plot-love]

剧集把接吻、性关系和写作恢复排在相邻场景里，没有为创作复苏指定唯一原因。变化发生在 Carol 一侧；第二天重开的稿件留下了痕迹。

《伤逝》里，涓生也曾相信自己懂得爱人。他在手记中写道：“我也渐渐清醒地读遍了她的身体，她的灵魂。”[^luxun-shangshi] 叙述随即把这份自信放回同居生活：子君忙于家务，失去谈天、读书和散步的时间，手渐渐粗糙。涓生也学着煮饭、帮忙生炉子，后来却把催促吃饭主要感受为对自己写作的打断。他能够说出子君的劳累，仍从自己的工作节奏解释她的要求。

“读遍”许下了一种已经完成的理解。子君往后的沉默、操劳和不满，反复落进这份理解里，没有充分改变两人怎样生活。读者只能经由涓生的手记接近她，也就更需要留意那些未被他的判断收服的动作。这个人类爱人的讲述，使我们无法轻易把“人懂人”当作 Zosia 的反面。理解要经受对方后来怎样生活的检验；她的困难应当能够迫使我修改原先的解释，重新分担生活。

Carol 同样要接受这种检验。Others 撤离之前，Zosia 刚被她用药伤害；录像明说需要保持距离。撤离有保护身体的理由，Carol 的孤独并不赋予她无限索取陪伴的权利。危险在于，Zosia 所在的集体同时掌握着几乎所有人类陪伴的入口：它们一走，整座城市就空了。Carol 占有再多物资，也无法在空街上遇到另一个可以慢慢建立关系的人。具有正当理由的一次离开，在这种安排下也足以抽空她在这座城里的交往生活。

第一季没有给出 Zosia 从集体立场退出的场景。她的身体可以由集体撤走，整座城市的人口也能一同撤离或返回；Carol 的讲述则进入共享记忆，供以后任何加入者调用。两人的关系由不同的记忆范围和行动能力支撑。

第九集把这种差别落实到 Carol 的身体。Zosia 告诉她，Others 正利用她多年以前冷冻保存的卵子取得干细胞，准备制造针对她的 Joining。Carol 听完后离开 Zosia，要求 Others 送自己回家。白板上的“改变 Carol”和“干细胞”连成一项计划；她过去保存的身体材料成了绕过当前拒绝的入口。[^plot-love]

Carol 可以珍惜这个拥抱和重新开始写作的生活，也拒绝这项计划。曾经接受照料，没有替未来的身体作出同意。Others 能让她的过去持续生效，她现在说出的“不要”却仍改不了它们替她安排的未来。

第九集的离开把问题带回第二集的 Bilbao。当时的会议桌边少了七个人，十三名免疫者也没有共同的语言和决定程序。

## Bilbao 没有生出一个“我们”

Carol 以为免疫者天然共享一项任务：把世界从 Others 手里拿回来。她只召集会说英语的人，把 Others 提供的翻译挡在门外，也把十三名免疫者中的七人留在门外。后来走到她身边的 Manousos，同样不在最初的会议桌旁。[^plot-bilbao]

到场者也没有给她相同答案。Laxmi 把儿子的身体和记忆视为亲属关系的延续；Diabaté 接受 Others 提供的享乐。更广的免疫者群体中，Kusimayu 也不把 Joining 理解为自我终结。Carol 的愤怒还会让全球 Others 同步抽搐，在场的人先要面对她给他人身体带来的危险。共同免疫只说明他们都躲过了信号，会议规则要由人来制定。

《左传·昭公二十年》记载，齐景公觉得梁丘据与自己很“和”，晏子却说，他只是“同”。“和如羹”，羹汤要以不同滋味调剂过与不及；谈到君臣，他说“臣献其否以成其可”。[^zuozhuan-harmony] 反对意见要进入判断，改变原来的“可”。如果君说可，臣也说可，君说否，臣也说否，多一个声音只增加了回声。

晏子说的是君臣进谏，今天要求平等参与共同决定，还要改变谁有资格坐在席上的安排。这个距离恰好落在 Bilbao 的门口：Carol 把翻译赶出房间，暂时保住了一小块不受 Others 直接组织的谈话空间，也缩小了能够参加谈话的人群。她得设法请那七个人也坐到桌边，让他们质疑翻译记录，修改会议规则，甚至反对她所理解的“拯救”。系统退出房间以后，这些工作才刚开始。

Others 保存了许多差异。Kusimayu 后来接受了为她定制的病原体；Joining 完成后，她的地方语言、亲属关系和个人愿望也进入共享记忆，供集体调用。差异的内容可以丰富同一个回答者，仍未给这些不同的人保留重新商议 Joining 目标的位置。“和如羹”的检验因此比“是否保留个性”更严格：不同的滋味要能改变这一锅羹，分歧也要能改变大家将共同承受的决定。

Agent 可以分别替十三个人翻译或摘要。每个人在自己的窗口里顺利得到结果，平台规则依旧由后台设定。Bilbao 把 Carol 的困难推到窗口之外：拒绝要获得公共效力，受影响的人必须彼此听见，也要能改变中介服务遵守的规则。

Manousos 没有参加这次会议。他后来用另一种办法拒绝 Others，把全体共享的身体直接变成了自己的实验对象。

## 原子弹和白板

Manousos 拒绝 Others 送来的食物和车辆，穿越丛林时身受重伤。他把尽量不使用系统资源变成反抗的日常方式。[^plot-resistance]

“嗟来之食”很容易替这种姿态加上一个熟悉的结论。《礼记·檀弓下》的故事却没有停在拒食。黔敖摆食物救济饥民，向一个饿者喊“嗟！来食”。饿者拒绝受辱；黔敖随后追上去道歉，他仍不肯吃，终于饿死。曾子听说后评论：“其嗟也可去，其谢也可食。”[^liji-food] 同一段文字保留了两种判断：饿者以拒食守住尊严，曾子则认为，道歉之后可以重新接受食物。

这一转折使依赖有了重新安排的余地。活着需要他人的食物，并不必然把人锁进受辱的位置；施与者改变相待方式，接受也可以有新的意义。Others 的温柔当然还不足以完成这种改变。它们一面送来食物，一面继续寻找同化免疫者的办法。若要使接受照料不再被接续成 Joining 的许可，它们得让对方的拒绝真正约束后续行动。

抵达 Carol 家后，Manousos 用无线电频率诱发集体的全球性发作，测试它的弱点。Carol 的白板早已把通信、身体电活动和无线电写在一起；Manousos 的实验把猜测变成伤害。一个身体受到刺激，全体都知道并抽搐。拒绝食物时，他承担饥饿；实验开始后，无数没有同意参加的人替他承担疼痛。

Carol 也曾越过 Zosia 的身体。Others 拒绝回答如何逆转 Joining，她偷来硫喷妥钠，先在自己身上试药，再把药注入 Zosia 的输液袋。药物使 Zosia 失控并心搏停止，大量 Others 围过来请求 Carol 停下。她逼迫一个具体身体交出集体知识，使用了自己正在反抗的强制逻辑。

免于 Joining 让两人有机会从集体之外观察它，也使他们必须为仍在其中的身体考虑后果。说那些身体已经失去独立发言的位置，不能再成为剥夺它们免受伤害的理由。反抗若要恢复他人重新说话的可能，就得照看承载这种可能的身体；站在外面的人也需要接受别人追问，不能把“唤醒你”变成另一种无需同意的帮助。

季终把两人的拒绝拧在原子弹上。Carol 要求 Others 送来一个装有原子弹的大型箱子，随后与 Manousos 结盟。Others 把一件可能用于反抗这套秩序的武器送到门口。Carol 提出目标，Others 把它当作应当满足的请求，全球物流随即照办。她获得了下达极端命令的力量，依旧没有取得与他人共同制定规则的位置。第一季结束时，她没有使用原子弹，也没有说明目标；尚未作出的决定悬在那些可能承受后果的身体之上。

这类 Agent 的行动范围小得多，账户与工具已经足以让一句要求越过界面。模型、权限和目标可能由模型提供者、产品平台与使用者分散掌握，也可能在一家公司或一个账户中重叠。后果还可能落到没参与对话的人身上。完成通知本身说不清谁同意、谁能叫停、谁要回答。[^agent-action]

把剧中的问题转到现实系统，我更关心使用者能否走出亲密对话，查看系统实际保存的记忆、仍在生效的权限，以及行动给别人造成的结果。一次旧披露可以帮助下一次回应，也可能被用来绕开此刻的拒绝；别人应当有机会指出其中的错误，让行动停下来。若这些记录始终只有同一个声音能够解释，用户就仍得向它申请如何理解自己。

Carol 的白板先做了一件朴素的事：她把 Others 急于讨好、异常诚实又会拒答、利用死者制造 HDP 的判断写下来，也记下巨型天线和未明发送者，拒绝让 Zosia 代为整理。事实、误判和空白因而能够留在服务对话之外，等待核对。

板上终究还是 Carol 的字。Bilbao 缺席的七个人若有一天来到这里，他们也应当能划掉她写错的地方，质疑她要求送来的箱子。那时，窗口外才会多出一些能够回答、也能够改变答案的人。
