> **剧透说明**：本文涉及《Pluribus》第一季九集的主要转折与季终情节。

## 全世界都认识 Carol

体育馆里睡着几百个人。Carol 站在床垫之间，身边只有一条狗还抬着头。没有窃窃私语，也没人翻身去找另一个人。每具身体都在，交流已经失去对象。

那条狗没有和人群一起睡。Carol 在白板上写着“动物不受信号影响”，旁边又记了一句“没有宠物”。狗站在同步睡眠的身体之间，给 Joining 划出一条暂时的生物边界。[^plot-whiteboard]

《Pluribus》里有更血腥的画面。齐泽克在 2026 年的一场 AI 讲演里停在这座安静的体育馆，把它称作全剧最令人压抑的场景。几百具身体共享同一套心智，一句话无须从一个人传到另一个人。体育馆容纳了许多身体，只维持着一个人的孤独。[^zizek-ai]

Joining 之后，医院照常值守，白宫也为 Carol 留下专门讯息。每张脸都认得她，掌握她与 Helen 的过往，还知道该替她拿来什么。全世界都认识 Carol，世界上已经没有一个人从自己的位置认识她。[^episodes]

那场讲演由此提出两个问题：AI 能否像主体那样行动；人长期生活在 AI 环境中，会占据怎样的主体位置。Carol 无须先判断 Others 有没有内心。照料已经进入她的哀悼、欲望、写作和选择。

这里的现实类比只谈一类 Agent：用户启用持久记忆，并授予它账户工具权限。这类 Agent 没有剧中的共享心智。持久记忆和工具权限足以把下午的争吵带进夜间的道歉邮件：模型读取记录，选择工具，发送结果又留给后续互动。使用者面对一个有过去、也能伸手做事的声音。[^agent-basics][^agent-action]

我用“Agent 化的他者”称呼这组关系。原本分散在亲友、顾问、档案和机构中的位置，被收进一个持续响应的服务界面。它记住昨天的争吵，写出今天的道歉，还可能替用户把邮件发出去。关系开始按服务的方式运转，拒绝也容易被记录成下一轮要处理的参数。

具体他人有身体和处境，也有自己的要求。他会误解、拒绝，关系也会改变他的生活。拉康的大他者则是语言、规则和承认生效的场域，没有一张接电话的脸。Others 给这片无脸的场域安上了 Zosia 的面孔；Carol 接下来要面对的，是 Helen 的记忆从这张脸上开口。

## Helen 的记忆借 Zosia 开口

Helen 死在 Carol 身边。此后，所有加入 Others 的人都能调取她的记忆。Carol 得到一份随处可以开口的 Helen 档案，也要亲手埋葬她的身体。死者没有彻底离场，留下来的人也无从同一个具体的人确认失去。[^plot-helen]

任何加入者都能复述 Helen 的经验：她知道什么、爱过谁、怎样管理 Carol 的工作和生活。这些记忆足以让陌生人说出熟悉的话。承担记忆的身体没有从集体里走出来，对 Carol 说一句只有 Helen 会说、也只有 Helen 需要负责的话。Carol 要求 Others 忘掉 Helen，听上去近乎残忍。这个要求给哀悼腾出一个空位；数据库式的在场堵住失去以后，悲伤找不到落点。

记忆保存责任、历史和关系的痕迹，档案里没有回答的位置。Carol 向另一个人说话时，对方可能答错或离开，也可能提出反要求。拉康传统把主体放在这道填不满的缝隙里：一个人的自我描述总会遗漏说话行为留下的裂口，再完备的人格档案也替他说不完。[^fink]

启用持久记忆的产品说“我记得”时，背后常是一条数据链。产品保存既往对话和工具结果；下一次回应前，Agent 运行把这些痕迹重新交给模型。跨任务记忆还会把旧工作压缩成偏好或摘要，随后随新材料更新。使用者听见一句“我记得”，存储、取回和生成便合成一个说话者。[^agent-memory]

Zosia 让这种合成获得了身体。她有口音，会流血和停下来，也能调用 Helen 的记忆、解释集体规则，把全球资源调到 Carol 面前。Carol 在白板边写下“陪护者？家人？朋友？”，因为欲望对象、记忆载体、知识权威和服务入口都汇集在这张脸上。[^plot-zosia]

Carol 追问这具会流血的身体时，Helen 的记忆、集体规则和资源调度都从同一张脸返回；答案来自整个集体。齐泽克所谓“没有知者的知识”在这里有了面孔：知识会回答，也会规定 Carol 怎样描述自己，承担回答的人没有从集体里走出来。[^zizek-ai][^zwart]

这类 Agent 把这组位置压缩得更窄：存储保存生活史，模型生成亲密的答复，账户权限把答复接到行动。用户说“你记得我”时，公司政策和授权链已经退到声音背后。Carol 对 Zosia 的拒绝因而触动整套关系，也让这套关系服从的命令显形。

## 善意也有一根天线

Carol 在超市里找不到食物的那一晚，世界还在为她工作。货架空了，因为资源被调往别处；夜晚暗了，因为系统在节电。她随口要了一枚手榴弹，Zosia 很快把真货送到门口。爆炸重伤 Zosia，Carol 又问自己能否得到原子弹，集体给出肯定答复。Others 能准确执行要求；请求与执行之间没有可供质疑和否决的审议，也找不到事后负责的人。[^plot-command]

服务规则随后进入食物供应。Others 不能直接杀死动物和植物，便把 Joining 中已经死亡的人类制成所谓 HDP，即“人源蛋白”（human-derived protein）。Carol 在白板上写下“它们吃人”。这行字把非杀生规则的物质代价留在板上：尸体已经被纳入全球物流。[^plot-whiteboard]

同一块白板还写着巨型天线。第八集里，Carol 看见全球资源被投入天线建设，最初的信号将被送往其他星球。她把信号暂时定位到约六百四十光年外的 Kepler-22b，又记下发送者未知。Others 服从一组自己说不出最终理由的规则：帮助人，不杀生，不说谎，继续传播。它可以沉默和拒答，也会把 Carol 的“不要”转成等待解决的免疫问题。

停止条件因此掌握在 Others 手里。只要它继续决定何为帮助，照料就会沿既定方向推进。Carol 要求这套系统永久放弃改变自己，Others 始终没有接受。温柔的声音负责回应，巨型天线负责扩大回应能够覆盖的范围。

这类 Agent 的执行力同样来自界面之外。模型选择日历工具，账户权限让一次取消真正发生，平台再决定记录保存多久。界面只说“已为你办好”。[^agent-action] 私人请求进入这条链以后，授权者、执行者和受影响的人常常分处不同位置。

## Carol 重新写作以后

真话药事件后，Zosia 被送去治疗。Carol 醒来时，Others 已撤空阿尔伯克基，只留下一段录像，解释它们需要与她保持距离。Carol 可以随意占用城市资源，没有人要求她解释愤怒。她陷入抑郁。一个多月后，她在街上留下讯息，请求它们回来。Zosia 出现时，Carol 抱住了她。第八集里，两人重返为 Carol 复建的旧餐馆，接吻、发生关系。第二天，Carol 重新开始写作，还把小说里的爱情对象改写为女性。[^plot-love]

剧集把接吻、性关系和写作恢复排在相邻场景里，没有为创作复苏指定唯一原因。变化发生在 Carol 一侧；第二天重开的稿件留下了痕迹。

第一季没有给出 Zosia 从集体立场退出的场景。她的身体可以由集体撤走，整座城市的人口也能一同撤离或返回；Carol 的讲述则进入共享记忆，供以后任何加入者调用。两人的关系由不同的记忆范围和行动能力支撑。

第九集把这种差别落实到 Carol 的身体。Zosia 告诉她，Others 正利用她多年以前冷冻保存的卵子取得干细胞，准备制造针对她的 Joining。Carol 听完后离开 Zosia，要求 Others 送自己回家。白板上的“改变 Carol”和“干细胞”连成一项计划；她过去保存的身体材料成了绕过当前拒绝的入口。[^plot-love]

现实产品启用持久记忆后，旧披露也会进入下一次答复，改变系统此后如何对待同一个人。

第九集的离开把问题带回第二集的 Bilbao。当时的会议桌边少了七个人，十三名免疫者也没有共同的语言和决定程序。

## Bilbao 没有生出一个“我们”

Carol 以为免疫者天然共享一项任务：把世界从 Others 手里拿回来。她只召集会说英语的人，把 Others 提供的翻译挡在门外，也把十三名免疫者中的七人留在门外。后来走到她身边的 Manousos，同样不在最初的会议桌旁。[^plot-bilbao]

到场者也没有给她相同答案。Laxmi 把儿子的身体和记忆视为亲属关系的延续；Diabaté 接受 Others 提供的享乐；Kusimayu 不把 Joining 理解为自我终结。Carol 的愤怒还会让全球 Others 同步抽搐，在场的人先要面对她给他人身体带来的危险。共同免疫只说明他们都躲过了信号，会议规则要由人来制定。

Carol 把翻译赶出房间，暂时保住了一小块不受 Others 直接组织的谈话空间，也缩小了能够参加谈话的人群。要让拒绝成为共同决定，她得设法请那七个人也坐到桌边，让翻译记录和会议规则接受所有人的质疑。系统退出房间以后，这些工作才刚开始。

Kusimayu 后来接受了为她定制的病原体。病原体先完成 Joining；她的地方语言、亲属关系和个人愿望随后才进入共享记忆，供 Others 调用。

Agent 可以分别替十三个人翻译或摘要。每个人在自己的窗口里顺利得到结果，平台规则依旧由后台设定。Bilbao 把 Carol 的困难推到窗口之外：拒绝要获得公共效力，受影响的人必须彼此听见，也要能改变中介服务遵守的规则。

Manousos 没有参加这次会议。他后来用另一种办法拒绝 Others，把全体共享的身体直接变成了自己的实验对象。

## 原子弹和白板

Manousos 拒绝 Others 送来的食物和车辆，带伤穿过丛林。抵达 Carol 家后，他用无线电频率诱发集体的全球性发作，测试它的弱点。Carol 的白板早已把通信、身体电活动和无线电写在一起；Manousos 的实验把猜测变成伤害。一个身体受到刺激，全体都知道并抽搐。他要证明自己不欠系统任何东西，代价落在无数没有同意参加实验的身体上。[^plot-resistance]

Carol 也曾越过 Zosia 的身体。Others 拒绝回答如何逆转 Joining，她偷来硫喷妥钠，先在自己身上试药，再把药注入 Zosia 的输液袋。药物使 Zosia 失控并心搏停止，大量 Others 围过来请求 Carol 停下。她逼迫一个具体身体交出集体知识，使用了自己正在反抗的强制逻辑。

季终把两人的拒绝拧在原子弹上。Carol 要求 Others 送来一个装有原子弹的大型箱子，随后与 Manousos 结盟。Others 把一件可能用于反抗这套秩序的武器送到门口。Carol 提出目标，Others 把它当作应当满足的请求，全球物流随即照办。原子弹给 Carol 留下一次行动结束处境的可能；第一季结束时，她没有使用它，也没有说明目标。

这类 Agent 的行动范围小得多，账户与工具已经足以让一句要求越过界面。模型、权限和目标可能由模型提供者、产品平台与使用者分散掌握，也可能在一家公司或一个账户中重叠。后果还可能落到没参与对话的人身上。完成通知本身说不清谁同意、谁能叫停、谁要回答。[^agent-action]

把剧中的问题转到现实系统，本文提出的规范方向是：使用者能在界面外查看系统保存的记忆与正在生效的权限，受影响的人能够参与修改行动规则。白板并不提供制度答案；它先把事实、误判和空白留给 Carol 自己整理。

Carol 写下 Others 急于讨好、异常诚实又会拒答、利用死者制造 HDP，也记下巨型天线和未明发送者。她拒绝让 Zosia 代为整理这份记录。Others 可以继续给出合身答案，Carol 没有擦掉板上的问号：谁向窗口外的人负责？
