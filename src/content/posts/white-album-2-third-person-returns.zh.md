《开樱 GRAPH》发售当天，雪菜读到了封面上字号最大的名字：冬马和纱。内页是春希写的专访，还有在斯特拉斯堡街头拍下的照片。

春希早在校对时便想过，雪菜也许会认出来。于是他主动删掉大教堂和有辨识度的街景，没有写采访地点，只留下足以刊行的正文与照片。文章没有虚构采访，也没有捏造和纱的履历；它只是把能够让雪菜拼出那次会面经过的线索压到最低。雪菜还是从刊物中确认了那次被隐瞒的会面。[^report]

她没有问春希为何见和纱。她先重复自己以前说过的话：“我不会要求你不要见她。”紧接着才说出真正介意的事：见面以前，她想知道。

这篇报道使 Coda 的问题第一次有了可以拿在手里的形状。隐瞒经过取景、删改、校对和发行，最后印在了纸上。春希删掉地标，也就在决定雪菜何时知道、能知道多少。

[上一篇《没有钢琴的三年》](/posts/white-album-2-three-years-without-piano/)写到，CC 让长期缺席的和纱在斯特拉斯堡重新开口，随后的采访任务又保证两人还会正式见面。到了 Coda，第三人已经不在关系之外等候。她是专访对象、职业钢琴家、病人的女儿，也是春希反复照护的人；雪菜进入唱片公司，仍是春希的恋人，戒指又惊动了小木曾家。三个人都有具体的工作身份。任何一次见面都会改动稿件、行程、病历或演出安排，也会牵动双方家庭。

丸户史明谈 Coda 时，特意把“成年人的决定”放进辞职、交接和告别这些实事里：人可以抛下原有生活，也得亲口向单位和身边的人说明，完成应做的交接，事后不能把责任推给别人。[^creator]

以下只看人物做了什么：谁先开口，谁把话落实为婚礼、分手、离境或继续见面；决定在半途交给了谁，最后谁负责收尾，又有谁连完整经过都没听见。

先这样记：浮气线的一冬由和纱提出并叫停；冬马 True 的决裂由春希发动；雪菜 True 里，是雪菜救回和纱，重新安排三个人的位置。Coda Normal 则从三条非浮气路线共经的危机，直接跳到春希心中的选择和一年后的婚礼筹备。每条线都在半途换手，先开口的人未必负责收尾。

## 最后的按钮以前，谁已经替谁决定

Coda 开场先给春希和雪菜各安排一张名片。春希进入开樱社，负责采访、校对和杂志企划；雪菜进入唱片公司公关部门。两人在会议室交换名片，周末再商量旅行与求婚。工作给了他们代表机构安排行程、接手专访、选用照片和接触艺人的资格。

斯特拉斯堡的重逢便从这些安排中生出。原定记者临时把差事让给春希，雪菜按约赶到欧洲会合；和纱每年到当地休假，曜子的事务所又接受了专访。三条日程在平安夜交会，看似偶然的重逢已有差旅、休假和采访作前提。

春希先在街头照料一个受伤的女人，认出和纱以后仍然留下。他替她保暖，处理脚伤，背她移动。这些动作确实减轻了伤者的痛苦；人道、责任和“不能把伤者扔在雪地里”也给了春希一张通行证，让他能够靠近早已想靠近的人。[^care]

雪菜在电话另一头只知道春希正在照顾“那个人”，于是称赞他做得对。春希知道自己破坏了一周以内必须见面的约定，也知道伤者是和纱；和纱知道雪菜在等，仍请求他留下；雪菜只能依据删节后的事实评价这场照护。春希照顾了和纱，也替雪菜规定了她据以判断的版本。

回国后，春希告诉雪菜自己见过和纱，却在途中停下，认定“说到这里已经够了”。雪菜想三个人重逢，也会嫉妒、害怕，甚至怀疑这份愿望有多少出于真心。她从未要求春希永远不见和纱；她只要求他见面以前告诉自己，让她有机会生气，也有机会决定要不要参与。

那篇报道随后把隐瞒做成了一本杂志。春希删去地标，又盼着刊物发行时和纱已经离日，往后便不必再解释。雪菜读到的，是经他整理后才公开的往事。

曜子又把一次采访扩成一个月的独家企划，并要求春希亲自拒绝和纱。春希拨给正在排练的雪菜，期待她责备、哭泣，替自己给出拒绝任务的理由。电话一直没有接通。[^assignment]

春希先等雪菜替他否决。电话没接通，他才接受采访，并把它称作“自己负责”。菜单不再询问接不接受，两个选项都通向接受；玩家只能决定，他肯不肯承认自己是为了和纱。

后面的菜单继续追问他怎样给行动命名。缺席雪菜演出，他可以承认自己“不去”，也可以说“去不了”；和纱靠上来时，他可以“抱紧她”，也可以把回抱说成只是借出胸口。玩家每按一次，都在替春希描述自己。

独家采访又把职业保密和私人隐瞒缠在一起。和纱拿票独自看了雪菜的演出，既看见台上的光，也知道那背后有三年哭泣。她没有去后台，转而借采访保密要求春希继续瞒着雪菜。原本保护未刊工作的规则，这时也隔开了本来就在关系中的雪菜。

演出失败后，和纱掌掴春希，逼近他，又以亲吻相逼。攻击、嫉妒和求他靠近同时涌出来。她最后提出一项限时安排：真正的爱给雪菜，假的爱给自己，只过完这个冬天。

春希知道，一旦说了爱、相互拥抱，甚至发生关系，便不能再用“假的”同内心隔开。他说自己必须决定伤害谁，转眼又把混乱归给发烧，承认此刻仍不肯选。游戏却记得他先前怎样回答：坦白停在哪里，是否承认自己主动靠近和纱，雪菜又知道多少。较早的回答会让后面的选项变暗，甚至使整组菜单消失。他先前给行动起过的名字，成了后来语言的边界。

最后一层菜单也没有把两个名字并排摆出。两句话是“我爱雪菜”和“我不能对和纱说谎”。前一句确认仍然存在的爱情，后一句承认他已无法把对和纱的感情继续叫作假戏；它们本可同时为真。玩家只能选择先照哪一句行动。此时雪菜已经要求知情并拉开距离，和纱已经演出、回避并提出一冬关系，春希也已经接受采访、删稿、照护和隐瞒。最后的按钮出现时，三个人早已作过一连串选择；按钮只是把这些动作推向不同结局。

Coda 因而有四个结局，却没有一张四选一菜单。“放开手”会先锁定浮气线；拒绝当夜的假爱，才会来到最后两句话。它们是否出现、最终通向哪里，已经受此前的坦白和行动限制。其余三条路线都要先处理手伤、专刊、曜子病情和婚约，才分向 Coda Normal、冬马 True 与雪菜 True。[^routes]

## 一条线省略告知，一条线交出收尾

### 三条非浮气路线先经过同一段生活

春希拒绝“一冬的假爱”时，和纱的右手早已被破窗玻璃割伤，左手腕也在当夜扭伤。他向编辑部汇报，却把两处伤都写成演出后跌下楼梯。破窗、争执、告白和同处一室没有进入报告；编辑部依照春希给出的版本改期，并安排后续工作。

春希留在和纱房间，做饭、换药、协助洗澡、喂食，夜里握着她的手。和纱先把告白收回成发烧时的胡话，很快又说，发烧的人反而不容易撒谎。两人都知道那句告白没有消失，谁也不必马上回答。伤口每天需要处理，今天于是自然延长到明天。

春希起初把停留归给手伤、曜子失联和自己的责任。旁白却留下更直白的一句：不是和纱不肯放他走，是他没有放开和纱。手伤需要照顾，也让春希每天进入她的房间，安排饮食，碰到她的身体。照护为和纱解决了眼前困难，也替春希推迟了感情上的回答。

一篇采访很快扩成百页以上的冬马和纱特刊，这是春希第一次主导整本杂志。他联系事务所，掌握行程，选择采访和照片。和纱也回到事务所，向工作人员道歉，恢复练习，并决定照常举办追加公演。

春希随后得知曜子患白血病，开始安排接送、治疗和日常生活，又同曜子约好隐瞒病情。他们担心和纱在演出前再次崩溃，便替她决定何时知道。和纱察觉两人有秘密，却只能把异常理解成曜子请春希施舍同情。春希和曜子想保住她的演出，却让她连如何面对母亲的病都不能自己决定。

另一边，雪菜的戒指被家人发现。尚未完整宣布的许诺，经小木曾家、武也与依绪的谈话成了“婚约”。朋友打来祝贺时，和纱就在旁边。春希只说“今天看着你”，既不解释婚约，也不能说出病情。和纱趁他睡着离开，直接去找曜子；保密最终以曜子倒在女儿面前的方式破裂。[^normal]

这几周把四个人卷进同一场危机，却没有给他们同样多的事实。春希知道两份感情、病情、专刊和婚约，曜子又同他商量何时透露病情；和纱与雪菜只能依据春希删过的版本行动。三条非浮气路线从这里分开。

### Coda Normal：春希在心里选择，谁听见了

这一夜以后，春希独自走在雪中。他回想自己如何向别人索取答案，终于说今后不再问任何人，要亲自选择最重要的人。脚本没有写出对象，也没有呈现他怎样把决定告诉雪菜与和纱。冬马 True 与雪菜 True 随后继续写公开告知和对方的反应；Coda Normal 直接跳到一年后。

这段空白早已写进选项。如果前面的回答没有为雪菜 True 保留资格，尤其没有在大阪如实说出和纱，最后按下同一句“我爱雪菜”，仍会进入 Coda Normal。告白本身可以真诚；可在说这句话以前，春希仍没有把同和纱的经过完整告诉雪菜。雪菜或许会从旁人那里得知，也可能早已看穿他，春希却没有在事前交代。

一年后，春希事业顺利，同雪菜正式订婚，正准备六月婚礼。住所、生育、双方家庭和每日相处都有安排。和纱取消追加公演，从日本媒体消失。春希在雪里承认，对她的感情或许还会持续十年、二十年，甚至一生；随后他回到雪菜身边，继续说爱她。

春希与雪菜的生活有工作、家庭和日复一日的相处，两人的爱在这个结局里真实成立。另一份感情只说给玩家听。春希在心里选了雪菜，家庭、工作和婚礼把这个选择过成了日常。和纱在一年跳跃间退出日本媒体，雪菜则没有得到一个听完全部经过再回答的场面。脚本没有说这是春希安排的，但这份安稳确实少了和纱的在场与雪菜的回答。[^normal]

《幸せな記憶》的钢琴版承接日常街景与降雪。婚礼已经排上日程，春希的另一份感情仍停在雪中独白。

### 浮气线：和纱规定一冬，也负责结束

浮气线先由和纱提出形式。她把真正的爱留给雪菜，只向春希索取一冬的“假爱”，连这段关系叫什么、能维持多久都先说好。玩家随后替春希按下“放开手”。他原本扣住和纱双腕，阻止她伤手，一旦松开，双手反而取得拥抱和亲吻的自由。和纱发出提议，春希把它做成身体行动和路线结果。

这只手也并非每次都能放开。若春希此前在大阪如实告诉雪菜和纱之事，“放开手”会变成不可选。浮气线需要那场坦白没有发生：雪菜或许知道和纱在场，也可能看穿春希，春希仍未主动交出完整经过和动机。二人才有余地把接下来的一冬安排成秘密，把爱称作同情、肉体、发烧和一场双方都知道并不完整的假戏。

“假爱”给了他们联络暗号、见面日期、关机理由和离开期限。春希对雪菜的爱也是真实的，恰好成为这份契约的掩护：只要他仍爱雪菜，便能告诉自己，眼前的关系没有碰到真正的爱。

旅行途中，列车进入隧道，车厢暗下来。春希主动叫醒和纱，问她读过川端康成没有。列车驶出隧道，白色大地铺到窗外，旁白又说明这里并非《雪国》开篇的准确地点。[^snowcountry]

《雪国》开篇的岛村隔着车窗反光，看叶子照料病人；女人、病者与流动暮景叠在玻璃上，亲密先经过旁观者的目光。春希则叫醒和纱，让她贴近车窗，同自己等待白色世界。紧接着，他说“决定的是和纱，我只是没有反对”。主动叫醒、共同观看和继续旅行都由他实行，句子却把同意写成顺势。白天面对雪菜、同事和婚约的自己，也被他说成在人前表演；夜色中的二人才叫真实。

隧道和暴雪暂时封住外界，留宿仿佛由天气逼成。旅馆里，两人借假身份得到一间房，又把“快要结婚”从应付侍者的话变成私人誓言。和纱向春希伸手，两人互称夫妻，许诺永远在一起。这份誓言在当夜可以真诚；它没有向雪菜公开，也没有安排工作、住所、家人和冬天结束以后的生活。

天亮以后，和纱决定离开。春希回到雪菜面前坦白浮气；雪菜问他是否曾想起自己，他回答“一直都忘了”。旁白早已记录，雪菜的声音不止一次进入二人世界。春希的认罪仍夹着一层假话：只要把自己说成彻底背叛、无可挽救的人，他就不必承认两边都爱，也能要求雪菜不要给自己选择，让“独自下地狱”成为唯一结局。[^affair]

他把全部罪名揽到自己身上，却没有亲手叫停，也没有收拾留下的生活。和纱要求他放手，春希坚持由她亲手抽回；和纱结束一冬关系，又把已经崩溃的春希交给自己所谓“不共戴天的敌人”。一年后的演出上，春希提前离场，雪菜放弃返场追出去。画面随即切回和纱离开一周后的那一天：雪菜走进春希房间，开始用整整一年把他带回工作和日常。

浮气线的动作次序很清楚：和纱提出期限，春希同意并实行，和纱叫停，雪菜善后。雪菜不在一冬契约里，事后坦白也不能把她送回当时，让她决定是否接受。春希自罚得最狠，结束关系的是和纱，把他带回日常的则是雪菜。

拒绝秘密关系以后，最后菜单的另一句话是“我不能对和纱说谎”。它承认春希无法再把对和纱的爱叫作一冬假戏。向自己承认欲望只是起点；他还得把事实告诉雪菜，听她回答。

## 冬马 True：春希主动决裂，谁替雪菜作了回答

冬马 True 把春希的欲望变成了公开行动。路线开始时，和纱独自待在酒店套房，不肯回应。春希谎称她留下带有自杀意味的“再见”留言，逼酒店准备开门。钥匙尚未插入，和纱已经自己开门，当面拆穿谎话。春希借旁人对死亡的恐惧逼出谈话，也显示他已不肯让和纱以沉默结束这一夜。

他提出同和纱离开，随即又问她：是否愿意接受一个将背叛恋人、朋友、家人和工作的人。和纱听出了这句话的转手之处，指出春希把最残酷的选择整个丢给自己。五天后，她把问题推了回去：背叛雪菜，选择我。

春希把选择递给和纱，和纱又逼他亲口收回。他先提出离开，却想让和纱为最后答案署名；和纱拒绝做被救走的人，也不肯替他减轻罪责。“背叛雪菜，选择我”把回答重新压回春希身上。

接下来，春希亲自分手、辞职、交接，面对武也的愤怒，向小木曾家说明，并准备离开日本。曜子曾提出由三个人一起承担病情；春希拒绝了，因为那样会使自己无法选择和纱。过去“不离开”“永远在身边”和求婚的承诺在分手现场逐条返回。那些话当时可以真诚，春希后来的行动却使它们成为必须由他说破的保证。[^kazusatrue]

冬马 True 的力量就在这里。春希没有把决定停在一句“选择和纱”，而是让它穿过公司手续、亲友告别和跨国迁居。他承担了自己能够承担的社会代价。

冬马与雪菜也终于当面对话。和纱承认自己抢走春希，承认嫉妒使三人同行无法持续；雪菜则追问，她爱的是否只是理想化的春希。和纱提出放弃钢琴作为赔偿，甚至想伤害双手。雪菜拒绝这种等价，并本能地阻止她。失去职业和身体补不回一段恋爱；两人的敌意很深，仍没有深到可以旁观对方自毁。

春希切断婚约、朋友、工作和日本生活，代价人人看得见。他给雪菜的分手版本却删去了曜子的病情，又反复估量她：有家人、朋友和工作，应该比和纱熬得住。这些人确实会陪她，却不能代替她听完事实、亲自回答。

离开日本以后，春希与和纱建立了真实的新生活。他们在维也纳共同工作，照顾彼此的噩梦，也维持钢琴事业。两年间，两人几乎不谈雪菜与日本，仿佛只要不提那些名字，决裂就追不到维也纳。游戏先播放《closing》，再把时间推到片尾后的两年。曜子发来一封近况邮件，末尾附着压缩文件。春希下载、解压，屏幕上出现抱着旧吉他的雪菜。她报出《POWDER SNOW》，歌声随即进入房间。[^video]

这段影像由雪菜和那些被春希切断联系的朋友录制。春希与和纱并肩听完，维也纳的二人生活没有因此消失；被留在日本的人也终于以文件、旧吉他和歌声进入这个房间。春希完成了自己的社会告别，却不能替共同历史宣布完结。

雪菜 True 从另一处起步：春希先把事实告诉雪菜，再请她处理眼前危机。此后带着三个人往前走的是雪菜。

## 雪菜 True：雪菜去见和纱，最后仍由她收尾

这一切要从大阪的坦白说起。春希可以说“只是想见你”，遮住自己也在逃离和纱，随后同雪菜以身体和解；也可以如实说出和纱。后一条分支里，两人没有亲吻、拥抱或发生关系，只把和纱之事和各自的感情说清。终局再说“我爱雪菜”时，雪菜已经从春希那里听到足以改变判断的事实，不必靠旁人线索或自己识破。她有机会生气、拒绝，也能决定是否介入。

春希随后请雪菜救和纱，并说事情结束以后听她决定。雪菜立刻指出其中的次序：他此刻最关心和纱，两人留下的问题却要由自己收拾。她听见了这份不公平，仍然动身去见和纱。这一刻，春希开口求她，雪菜却接下了救人和事后安排两件难事。

曜子可能死亡，雪菜便从医生、葬礼、亲属、工作和往后的联系谈起。即使曜子去世，也会有人陪和纱办葬礼、处理工作，再陪她过后面的日子。和纱把这种爱叫作方便的谎言；雪菜仍回答自己爱她。两人接下来争的，是这句话能否变成探访、演出和下一次见面。

这场冬雪冲突不能再用告别收尾。春希不在场，雪菜追问和纱五年前为何离开，为什么把三个人的问题拖到现在；和纱反击她已经得到一切，却还站在失去一切的人面前说教。她们互称胆小鬼与伪善者，掌掴、拉扯，道歉以后又重新攻击。谈话没有得出整齐答案，冲突过后两人仍得面对同一场演出和下一次见面。[^setsunatrue]

![冬马与雪菜发生身体冲突，和纱向后仰身，雪菜扬起手，春希不在画面中。](./white-album-2-third-person-returns/coda-setsuna-true-direct-conflict.jpg)

*春希不在场时，冬马与雪菜以语言和身体直接冲突。画面不替任何一方判定胜负。PS3 版实机画面：©2012 AQUAPLUS / via xueyinhualuo, Bilibili。*

雪菜更会说，也更会调动家庭和工作关系；和纱会动手、讥讽，拿离开相逼。两人都能打断对方，逼对方重说。她们没有和解，却能当面驳回对方的说法，再带着没谈妥的部分走向同一场演出。

和纱随后承认自己仍爱春希，会嫉妒雪菜，也请求不要把她排除。雪菜没有要求她撤回感情，而是给春希打电话，请他拿起吉他；春希把电话调成扬声器。上一篇末尾那场没有钢琴的演奏，只能把歌单向送给远方的和纱；这一次，和纱能够当场听见、回答，并约定下一次由钢琴加入，录成完整版本。

和纱今天在电话里听，下一次便会带着钢琴走进录音室。三个人约好了时间，也约好了各自的声部，这首歌终于不再停在单向的留言里。

雪菜回看 IC，承认自己一面要求三个人永远在一起，一面抢先把春希拉进二人关系；和纱承认嫉妒，也承认无法只把雪菜当成敌人。最后，和纱亲口要求春希回到雪菜身边，不能再同等对待两个人。春希随即说出差别：他喜欢和纱，爱雪菜，要同雪菜结婚。

和纱可以作为朋友和音乐上的伙伴留下；春希要结婚的人仍是雪菜。她可以同两人吃饭、录音，继续爱春希，婚恋的位置却没有因此变成三人平分。

春希求婚以后，又催雪菜给出答案。雪菜指出他再次把最困难的部分丢给自己，掌掴他，随后把长期没有发送的邮件一封封发出。手机提示音连续响起，支持、嫉妒、恐惧、愤怒和对职业秘密的怨恨依次抵达。那些曾被“我理解”“我没事”压住的话，终于有了各自的发送时间。[^mail]

雪菜给自己五分钟发怒，也给愤怒设下期限。她逼春希听完那些从未消失的嫉妒、恐惧和怨恨。五分钟到了，仍是雪菜宣布争吵结束，答应继续做最懂他的人。

随后，编辑部完成特刊；小木曾家把和纱请上饭桌；三个人又把作词、作曲、吉他、钢琴和演唱录成唱片。录音室里，和纱与雪菜并肩站在钢琴和设备前，春希在画外。三个人要按工作日程再次见面，共同完成能够发行的作品。

![录音室里，雪菜与和纱并肩站在钢琴和录音设备前。](./white-album-2-third-person-returns/coda-setsuna-true-recording-studio.jpg)

*三人在录音室再次见面，作词、吉他、钢琴、演唱与录制成了共同工作。PS3 版实机画面：©2012 AQUAPLUS / via xueyinhualuo, Bilibili。*

《時の魔法》的片尾 CG 接着展示新的日常。和纱公开留下，却不在婚约里；雪菜得到求婚，仍要同一个爱着和纱的人生活；春希保住工作、朋友和家庭。这条路从春希求援开始，雪菜去探望和纱、同她正面冲突，又打电话叫春希拿起吉他，让三个人回到同一首歌里；和纱随后把婚恋选择推回春雪，春希求婚，最后仍由雪菜回答。

雪菜 True 给三个人的说话和回应留了最多时间。爱、嫉妒和竞争都能说出，家庭、工作和音乐又保证他们会再见。压力也集中在雪菜身上：她既要听春希与和纱说话，又常常负责给争吵规定时限、恢复联系，把自己的怒气重新收进“理解”。

回头看，四条线都在半途换手。Coda Normal 由春希在心里选择，婚约、家庭和工作替他落实，却省去了公开告知。浮气线由和纱提议、春希实行，最后仍由和纱叫停、雪菜善后。冬马 True 的决裂由春希发动并得到和纱确认，留在日本的余波则由雪菜和朋友承受。雪菜 True 从春希求援开始，雪菜带着三个人重建联系；和纱退让，春希求婚，最后还是雪菜收尾。

先开口的人未必负责收尾，承担后果的人也未必听过完整事实。冬马 True 让春希承担最醒目的社会代价，却也让他替雪菜筛过事实；雪菜 True 让冬雪终于正面冲突，收拾关系的活儿仍大半落在雪菜身上。浮气线的自罚最重，结束秘密、把春希拉回日常的却是两位女性。Coda Normal 的生活最安稳，脚本也省去了告知和回答。

于是人很容易希望：把冬马 True 里春希的公开担责，与雪菜 True 里冬雪的正面冲突合到一条线上。但那是读者对现有路线的追问，并非游戏藏着的第四结局。四个结局只安排了眼前的选择，没有谁能替三个人把共同历史清零。
